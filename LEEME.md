# Orbe Apps

Sitio de Orbe Apps (apps para negocios pequeños de Latinoamérica), publicado con GitHub Pages en
**https://orbe7apps.github.io/orbe-apps/**

| Carpeta | Qué es | Dirección |
|---|---|---|
| `index.html`, `img/`, `logo.svg`, `portada.png` | Página web de Orbe Apps (servicios y precios) | `/orbe-apps/` |
| `apps/` | Las 4 microapps: Inventario, Agenda, Fiados y Presupuesto | `/orbe-apps/apps/` |
| `catalogos/` | Catálogos con pedidos por WhatsApp (base y ejemplo Dulce Hogar) | `/orbe-apps/catalogos/<negocio>/` |
| `contenido/` | Publicaciones y reels de Instagram, con sus fuentes y herramientas | (no se enlaza desde la web) |

## Demo y versión completa de las microapps
Cada microapp abre en **modo demo**: viene con datos de ejemplo y solo deja agregar 1 elemento propio.
Con un **código de activación** (formato `PRE-XXXX-XXXX`, o el enlace `?codigo=...`) se convierte en la
**versión completa**, vacía y lista para el negocio. Es la misma dirección para ambas.

| App | Demo / completa |
|---|---|
| Inventario | `/orbe-apps/apps/inventario/` |
| Agenda de citas | `/orbe-apps/apps/agenda/` (enlace de reservas: `agenda/reservar.html`) |
| Fiados | `/orbe-apps/apps/fiados/` |
| Presupuesto | `/orbe-apps/apps/presupuesto/` |

## Precios vigentes
Microapp $17 · Catálogo con pedidos $49 · Página de negocio $89 · App a medida desde $149 · Mantenimiento $7/mes.
